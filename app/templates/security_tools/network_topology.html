Security controls (policy narrative)

  • IT: server-segment access; inbound RDP blocked by default.
  • Smart infra: isolated VLAN; MQTT only to designated brokers.
  • Finance: strict RBAC; SMB signing in policy.

Simulated LAN: where events flow

Security events, PCAP samples, and SIEM-style logs in this project represent traffic on the paths shown under Logical LAN: source IP → routed path → host in a VLAN. Firewall and IDS pages apply policy on those same logical paths.

  1. External → edge: scan and phishing-style events from Threat Intel and the map.
  2. Lateral: cross-VLAN sessions in traffic analysis (Wireshark) and exploit labs as illustrative records.
  3. Real Nmap: when enabled, packets leave the Flask host toward your CIDR — separate from the ~200 simulated assets.

Application flow (browser ↔ Flask)

Each HTML page is served by Flask; Chart.js widgets call fetch("/api/v1/…") on the same origin; sessions use the Flask-Login cookie.

Attack map: the browser loads Carto basemap tiles (GET); coordinates are computed server-side — no SIEM payloads are sent to the tile CDN.
